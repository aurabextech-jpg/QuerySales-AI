## 4. Decisions made

| Decision | Alternatives considered | Why this one |
|---|---|---|
| One `ENCRYPTION_KEY` serves both Fernet (legacy) and AES-256-GCM (new) | Two separate keys | A Fernet key is url-safe-base64(32 bytes) which is exactly the 256-bit key AESGCM needs. One key, one failure mode. Documented in `.env.example`. |
| `uv lock` + `uv export` for requirements.txt | Hand-maintained requirements.txt | Vercel's `@vercel/python` reads `requirements.txt`. Export from lock guarantees local == deployed and prevents drift between the two manifests. |
| Direct-only deps in pyproject.toml | Full pinned deps in both files | Lets uv manage the transitive tree. The old approach listed 70+ transitive deps and masked missing direct ones. |
| Strip `channel_binding` from Neon URLs | Tell user to edit URL manually | Neon console auto-appends this libpq-only param; every user will hit it. Stripping is automatic and invisible. |

## 6. Discovered — affects later phases

1. **Gemini embeddings need explicit `dimensions=1536`.** `gemini-embedding-001` defaults to 3072 dims. Phase 3's `embed.py` must pass `dimensions=1536` to produce vectors matching the `vector(1536)` column (Decision D2). Without this, every embedding insert will fail with a dimension mismatch assertion.

2. **`datetime.utcnow()` is deprecated in Python 3.12+.** `agent_core/tracing.py` line 129 uses it. Not broken in 3.13 but emits `DeprecationWarning`. Phase 1 models should use `server_default=text("now()")` or `datetime.now(timezone.utc)` for new columns.

3. **Vercel supports Python 3.13** but defaults to 3.12. `.python-version = 3.13` is the authoritative mechanism; `requires-python = ">=3.13"` also works. Both are present.

4. **Neon `DATABASE_URL` from the console uses `postgresql://`** (sync driver) and appends `channel_binding=require`. Both must be normalised for asyncpg — now handled automatically in `db/session.py`.

5. **`.claude/skills/openai-agents-sdk/`** references `agent-service/` which doesn't exist. It's a loaded skill but not in scope of the Phase 0 rules fix.
